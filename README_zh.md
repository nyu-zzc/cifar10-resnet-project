# 参数不超过 500 万的 CIFAR-10 ResNet

**Zicheng Zhou · zz11018 · NYU Tandon Deep Learning，2026 秋季**

[英文首页](README.md) · [项目报告](reports/Zicheng_Zhou_Deep_Learning_Project_1_Report.pdf) · [结果 notebook](notebooks/reproduction.ipynb) · [复现指南](docs/reproducing.md)

这是我参加 CIFAR-10 ResNet Architecture Challenge 的课程项目。我先用较短的训练筛选结构和训练方法，再延长表现较好的模型，并结合识别错误安排后续实验。

最后保留的主要结构是三阶段 Wide ResNet。本地验证最高达到 **97.52%**；加入轻度外观增强后，公榜最高达到 **89.40%**。我选定的两个提交中，最终私榜成绩为 **86.30%**。

## 主要结果

本地结果统一使用 5,000 张验证图像、CPU FP32 和水平翻转预测。

| 模型 | 参数量 | 本地验证 | 公榜 | 私榜 | 最终选定 |
|---|---:|---:|---:|---:|:---:|
| 轻度外观增强 WRN，SWA | 4,480,474 | 97.36% | **89.40%** | 86.10% | 是 |
| 减少混合增强的 Robust WRN，SWA | 4,948,626 | 97.42% | 88.00% | 86.70% | |
| Robust WRN 对照，SWA | 4,948,626 | 97.40% | 88.60% | **86.30%** | 是 |
| Robust WRN 续训 50 轮，EMA | 4,948,626 | 97.48% | 88.60% | **87.30%** | |
| 本地最佳 WRN | 4,480,474 | **97.52%** | 88.40% | 85.50% | |

本地、公榜和私榜给出的排序有所不同。轻度外观增强的公榜表现最好，Robust 续训模型取得了所有候选中最高的私榜分数，最终选定成绩则来自 Robust SWA。报告中整理了这些结果以及对应的训练过程。

## 我做了哪些实验

项目共完成 **79 次训练、7,810 轮**，覆盖了残差块数量、通道宽度、卷积核、跳跃连接、池化、优化器、学习率计划、数据增强、正则化、蒸馏和量化。

主要模型是 WRN-28，宽度为 3.5，三个阶段分别使用 56、112、224 个通道，每个阶段有四个预激活残差块。Robust 模型把通道调整为 58、116、232，并加入 SE。所有模型都从比赛训练数据开始训练，统一使用 45,000 张训练图像和 5,000 张验证图像。

几项结果对后续选择影响比较大：

- 同样训练 400 轮，三阶段模型的本地准确率为 97.40%，四阶段模型为 96.80%。
- 训练早期延长轮数比较有效，后期低学习率续训的增益逐渐变小。
- 本地最佳模型的 124 个错误中，51 个来自猫狗互相混淆。外观变化下的表现促使我尝试轻度颜色、灰度和模糊增强。
- INT8 量化将验证准确率从 97.30% 调整到 97.26%，模型文件缩小到约 1/3.80，双线程 CPU 吞吐提升约 1.94 倍。
