# 可编辑图表包

本目录包含报告4张图的SVG、PDF、PNG，以及5份聚合源数据CSV、图注、数据哈希和绘图脚本。SVG保留可编辑文字，适合在支持SVG的矢量编辑器中修改；PDF适合排版插入，PNG是预览/Word兼容版本。未包含比赛原图、逐样本标签、账号截图或模型权重。

文件名沿用绘图项目内部编号，报告中的展示顺序为：训练曲线、架构比较、错误与模糊代理、官方分数。请以报告中的Figure1–4和caption为准。

## 重新绘图

在本目录打开终端，使用Python3.12环境：

```text
python -m pip install -r requirements.txt
python plot.py
```

脚本只读取随包的聚合CSV，不训练或推理模型，不访问网络。它会覆盖同目录的图文件，请先另存修改副本。当前CSV哈希由sources.json校验；只调整样式时不要改CSV。若确需纠正数据，应保留原始表格，记录更改依据，并显式更新对应表的SHA/行数，不能把人为改动继续当作原始实验结果。

每条训练曲线来自实际已完成单次运行，未平滑；不同训练时长、权重类型和精度不能直接当作同预算独立对照。官方private最高87.3%未被选中；最终所选结果为86.3%。
